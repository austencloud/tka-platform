Contributor Guide

Welcome to TKA

Clone the repo, type one command, and start fixing things. No keys, no config, no ceremony.

01 — Setup

Get Running

Five minutes. Three steps. Then you're working.

Clone and install

Grab the repo and install dependencies.

git clone https://github.com/austencloud/the-kinetic-alphabet.git
cd the-kinetic-alphabet
npm install

Create your Firebase account

Visit the web app and sign in with Google. This is a one-time thing—it creates the account the CLI needs to recognize you.

# Open in your browser:
https://tkaflowarts.com/create

Open Claude Code and go

Open Claude Code in the repo directory and type /fb. If you're not logged in yet, a browser opens for Google sign-in. Then Claude picks a feedback item and you start working.

# In Claude Code, type:
/fb

After you log in, send Austen your email so he can add you as a contributor.

02 — Workflow

How It Works

Bugs, features, and ideas live in a shared queue. You claim one, fix it, submit it. Austen reviews and ships.

03 — Commands

Slash Commands

Type these in Claude Code. Claude handles the rest.

/fb Pick the best unclaimed item and start working
/fb <id> Claim a specific item and start working
/done Wrap up and submit your work for review
/check Find and fix TypeScript errors
/commit Commit your changes in clean, logical chunks
/submitfb Found a bug? Submit it to the queue
/audit Audit a module for code quality
/monolith Detect files that need splitting
/deadcode Find and remove unused code
/ship Check if a feature is production-ready
04 — CLI Reference

Manual Commands

If you need finer control or prefer working outside Claude Code.

# See the queue
node scripts/fetch-feedback.js list

# Claim something specific
node scripts/fetch-feedback.js claim yfTRt6UK

# See what you're working on
node scripts/fetch-feedback.js mine

# View full details on an item
node scripts/fetch-feedback.js yfTRt6UK

# Submit your work for review
node scripts/fetch-feedback.js yfTRt6UK in-review "Fixed the layout bug"

# Keep your claim alive (they expire after 45 min)
node scripts/fetch-feedback.js heartbeat yfTRt6UK "still on it"

# Check your identity
node scripts/fetch-feedback.js whoami

# Full command list
node scripts/fetch-feedback.js help

What You Can Do

Admin only

  • Change priority

  • Archive items
  • Delete others' feedback
  • Manage developers
06 — Troubleshooting

If Something Goes Wrong

"Could not sign into Firebase"

Visit tkaflowarts.com/create and sign in with Google first. That creates your account.

"Permission denied"

Austen hasn't added you yet. Send him your email.

"Cannot claim — active work in progress"

Someone else is on it. Pick a different item, or wait 45 minutes for the claim to expire.

"Token refresh failed"

Run node scripts/fetch-feedback.js login to re-authenticate.

Browser doesn't open during login

Copy the URL from the terminal and paste it into your browser.
