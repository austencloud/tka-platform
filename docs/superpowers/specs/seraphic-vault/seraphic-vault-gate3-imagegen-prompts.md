# Seraphic Vault Gate 3 image-generation record

**Mode:** Built-in image generation, registered paint-over

**Use case:** `sketch-to-render`

## Desktop target

Image 1 was the Gate 2 desktop render and binding composition contract. Image 2
was the approved Seraph material and lighting reference. The request converted
the frame into a photorealistic heavenly environment while preserving the exact
camera, six feather ribs, clear performer floor, and four platform hierarchy.
It required dense layered clouds, cool weathered alabaster, warm feather edges,
and a white-gold solar focus. It prohibited added architecture, vegetation,
figures, celestial bodies, and geometry changes.

The first result introduced a second overhead solar hotspot. A targeted edit
removed only that hotspot and made the existing centered disc inside the
aureole the single light source.

## Portrait target

Image 1 was the Gate 2 portrait render. The corrected desktop target supplied
the material, cloud, and lighting anchor. The request preserved the registered
78-degree portrait camera, all four separated sanctuaries, the outer-rib crop,
and the central performer lane while matching the desktop target's material and
atmosphere.

## Landscape-phone target

Image 1 was the Gate 2 landscape-phone render. The corrected desktop target
again supplied the visual anchor. The request preserved the registered
32-degree panoramic camera, the deliberate outer-rib crop, all four separated
sanctuaries, and the central performer lane while matching the desktop target.

## Shared invariants

- One centered sun inside the existing ring.
- Six carved feather ribs and one broad clear performance floor.
- Broken Vigil lower left, Twin Choir lower right, Eroded Halo upper left, and
  Cloud Crown highest at upper right.
- No columns, temples, gardens, trees, plants, stars, moons, birds, people,
  angels, statues, waterfalls, coral, text, labels, borders, UI, or watermark.
