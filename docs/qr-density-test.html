QR Code Density Test

Each QR rendered at 200px (approximate poker-card width of 2.5"). Open this file in a browser to compare.

How to read this:
  • Version = QR spec version (1-40). Higher version = more modules = finer grid.
  • Modules = the NxN grid of black/white squares. More modules in the same physical space = harder to scan reliably.
  • At poker-card scale (~2.5"), QR versions up to about 10-12 (57x57 to 65x65 modules) scan well with modern phone cameras.
  • Beyond version 15 (~77x77), scanning reliability drops, especially in poor lighting or at distance.
  • Error correction is set to L (7%) to minimize module count. Using M or H would push versions higher.
