# Q3: Impact (150 words / 1,000 chars)
# What kind of impact do you hope your project will have and why? What specific audiences and communities will the project engage?

The Kinetic Archive reaches two audiences that rarely overlap. Flow artists get the first video game that takes their practice seriously, and the indie game community discovers an art form most people only encounter at festivals. Both leave with access to a working notation tool they did not know existed.

Flow artists know their practice has depth. The barrier is that no one has built the tools to codify it. The notation is the first serious attempt. The game is what happens when it works well enough to drive a 3D figure on screen.

The notation is open source. If it runs inside a video game, it can run inside a film, a VR experience, any digital medium. Other developers can build on it freely. The game is the first application in 3D, not the last. The game ends with the player opening the software and doing it.
