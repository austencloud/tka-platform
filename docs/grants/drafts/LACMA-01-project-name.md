# Project Name

The Kinetic Alphabet

## Rationale

The Kinetic Alphabet is the umbrella — the full system encompassing the notation, the web application, the rendering engine, the teaching materials, and the cultural artifacts (including The Kinetic Archive museum game). LACMA is funding the R&D work that underpins the whole umbrella plus its public demonstrations. Using the umbrella name rather than the museum-specific name matches the scope of what's being funded.

"Alphabet" primes a reviewer to think *systematic, structural, learnable* before they read the description. "Archive" is reserved for the museum subproject (the CC and Epic pitches).
