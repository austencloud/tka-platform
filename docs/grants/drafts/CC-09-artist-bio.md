# Artist Bio

## Short Bio (for application)

Austen Cloud is a fire performer, flow arts instructor, and software developer based in Chicago. He created the Kinetic Alphabet, a notation system for prop manipulation that has spread internationally since 2022 through published books, card games, and a companion web application. He has run Taco Tuesday Flow Jams in Palmer Square since 2017 and performed professionally with Cirque Aflame. He is currently developing The Kinetic Archive, the first flow arts video game.

## Resume Highlights (for reference)

- 9 years professional flow arts performance and instruction
- Creator of the Kinetic Alphabet notation system (2022-present)
- Developer of TKA Scribe web application (2024-present)
- Host of Taco Tuesday Flow Jams, Palmer Square, Chicago (2017-present)
- Performer with Cirque Aflame
- Published: Kinetic Alphabet guidebooks (multiple editions)
- Created: TKA card game for sequence sharing
- International distribution of notation materials at festivals
- Self-taught software developer (Svelte, TypeScript, Firebase, Unreal Engine 5)
- Fund The Flow Arts grant recipient
