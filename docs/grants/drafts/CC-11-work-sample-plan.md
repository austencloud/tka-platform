# Work Sample Video Plan

## Format
- **Length:** 3:00-4:30 (aim for ~3:30)
- **Recording:** OBS, 1080p, capture browser window + mic audio
- **Audio:** Live voiceover from bullet points. No script. No music.
- **Cuts:** Zero. One continuous take. If you fumble, start over.
- **Tone:** Casual, confident, like showing a friend. Not a tutorial. Not a pitch.

## Pre-Recording Setup
1. Browser fullscreen on best monitor
2. Clean browser (no bookmarks bar, no other tabs visible)
3. App loaded, Create module, empty sequence
4. Good background (dark, clean)
5. Close notifications, Slack, anything that could pop up
6. Mic set up and levels checked
7. Sticky note with bullet points next to screen
8. Do 2-3 practice runs before hitting record

## The Flow (~3:30)

### Beat 1: Opening (~10 sec)
Say: "This is TKA Scribe. I built it to write down flow arts choreography."
That's it. No history, no theory. You're in.

### Beat 2: Build the sequence (~60-90 sec)
Add beats one at a time at a deliberate pace. Narrate what you're doing, not what the app is.
- "I'm starting in alpha - both hands at opposite points."
- "Now I'm adding a shift, the hand moves to a new position."
- "Each pictograph encodes exactly what the body does."
Keep it sparse. Let gaps breathe. Don't narrate every click.
Pick a 4-6 letter word where each beat looks visually distinct.

### Beat 3: Play the animation (~30 sec)
Hit play. STOP TALKING. Let the animated figure perform the full sequence.
Let it loop once or twice. This is the payoff.
If you say anything at all: "That's the sequence." Then silence.

### Beat 4: Closing (~15 sec)
Quick browse of the sequence viewer/choreo card. Then:
"The museum game is built around this. The notation on the walls is real. This is the tool that writes it."
Done.

## Sticky Note (tape this next to the screen)
1. "This is TKA Scribe. I built it to write down flow arts choreography."
2. While building: what you're doing, not what the app is
3. Animation plays: stop talking
4. "The museum game is built around this. The notation on the walls is real. This is the tool that writes it."

## Word Selection
Pick the word BEFORE you sit down to record. Run it through the app twice. Confirm:
- Every beat produces a visually distinct pictograph
- The animation looks good (no weird transitions)
- It's 4-6 beats long

## Overthinking Trap
Set a timer: 30 minutes max for practice runs. After that, record your next clean take and use it. The reviewer spends 3 minutes on this. They need: notation exists, app works, animation plays, you can talk about your work. That's it.

## Underthinking Trap
Do the practice runs. Smooth confident flow reads as competence. That matters for a grant asking "can this person execute a multi-year project?"

## What NOT to Do
- Don't open settings or irrelevant menus
- Don't show broken or half-built features
- Don't rush the build to get to the animation
- Don't try to show everything the app can do
- Don't add text overlays or post-production edits
- Don't read from a script word-for-word (bullet points only)
