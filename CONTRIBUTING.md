## How to Contribute

- **Fork** the repository and work on a feature branch in your fork
- **Open a pull request** against `main`
- Write **clear commit messages** describing the why, not just the what
- For **non-trivial changes**, open an issue first so we can discuss the approach before you invest a lot of time
- Be kind in code review. The flow arts community is small and friendly; let's keep it that way.

## What's In Scope

- Bug fixes
- New features that fit the project's direction (open an issue first if you're unsure)
- Documentation improvements
- Translations
- New domain knowledge entries in the MCP server
- Accessibility and performance improvements

## What's Out of Scope
