## Beta Position Definition

**ID:** term-beta-position
**Category:** term-definition
**Difficulty:** easy
**Score:** 66/100

### Question

> What is beta in TKA?

### TIKA's Response

Beta is a position in TKA where both hands are at the same grid point. This means the hands are at 0 degrees apart from each other.

Examples of beta positions include:
- beta1: both hands at N (north)
- beta5: both hands at NE (northeast)

Beta is one of the three fundamental position types in TKA, along with alpha (hands at opposite grid points) and gamma (hands at adjacent grid points forming a right angle).

## Misconception: Types are Lettered

**ID:** misconception-type-letters
**Category:** misconception-correction
**Difficulty:** medium
**Score:** 76/100

### Question

> Is A a Type A letter?

### TIKA's Response

No, A is not a "Type A" letter. The correct terminology is that **A is a Type 1 letter**.

The 6 letter types in TKA are numbered 1-6, not lettered:

- **Type 1:** Dual-Shift (both hands shift) - includes letters A through V
- **Type 2:** Shift (one shifts, one static)
- **Type 3:** Cross-Shift (one shifts, one dashes)
- **Type 4:** Dash (one dashes, one static)
- **Type 5:** Dual-Dash (both hands dash)
- **Type 6:** Static (both hands stationary)

Letter A specifically is a Type 1 Dual-Shift letter where both hands shift between grid points.
