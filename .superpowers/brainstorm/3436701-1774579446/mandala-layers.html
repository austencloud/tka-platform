How should the two hand paths combine?

Each sequence produces a blue prop-tip path and a red prop-tip path. How do they form the final mandala?

A

Simple Overlay

Blue path drawn first, red path drawn on top. Both fully visible, colors overlap where paths cross. Like the VTG book patterns in your image — two distinct colored traces layered together.

B

Filled Petal Shapes

Instead of stroke paths, fill the enclosed petal regions with semi-transparent color. Blue petals and red petals overlap to create a third blended color where they intersect. More "mandala art", less "technical diagram".

C

Both — Context Dependent

Stroke-only for the card back (clean, printable, matches VTG tradition). Filled version for the animated/gallery view where it looks more dramatic on screen. Same underlying geometry, two rendering styles.
