Key Design Decisions

Transitions

Each stop slides/fades in (300ms ease). No jarring pops.

Bottom Nav

Hidden during entire tour. Tour owns the full screen.

Shuffle Delay

After user shuffles, wait 1.5s so they see the new path before advancing.

Fuse Result

Stop 4's Fuse button actually fuses. Tour ends with the result view showing.
