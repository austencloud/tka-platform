Reversal Boundary Rule

Proven across 69,888 combinations using cumulative (physical) reversal model.
Retraction

An earlier version of this page stated a different rule based on first/last step matching. That rule applied to the seeder's per-beat data model (each step independently assigned from original), not to physical reality. Prop reversal is cumulative: each reversal toggles from the running direction. The correct rule is parity.

The Rule

A reversal pattern produces a clean LOOP boundary if and only if each hand has an even number of reversals.

Even count → prop returns to starting direction. Odd count → prop ends opposite. Always.

Why?

Each reversal is a toggle: CW→CCW or CCW→CW. Two toggles return to start. Three toggles don't. Four do. It's the same reason flipping a light switch an even number of times leaves the light in its original state.

This is independent of which steps are reversed. Only the count matters.

4-Step Patterns — All Clean

Every named 4-step pattern has even reversal counts per hand. All loop seamlessly.

6-Step Patterns — Where Odd Counts Appear

Alternating and Long Book tile to 3 reversals per hand at 6 steps. Odd count = boundary mismatch. The prop ends spinning the wrong way.

Step-by-Step: Alternating at 4 vs 6

4 steps (2 reversals each — even):

Start: blue=CW red=CW
Step 1 (R): blue=CW red=CCW ← red flips
Step 2 (B): blue=CCW red=CCW ← blue flips
Step 3 (R): blue=CCW red=CW ← red flips back
Step 4 (B): blue=CW red=CW ← blue flips back
→ Loop: both CW = matches start ✓

6 steps (3 reversals each — odd):

Start: blue=CW red=CW
Step 1 (R): blue=CW red=CCW
Step 2 (B): blue=CCW red=CCW
Step 3 (R): blue=CCW red=CW
Step 4 (B): blue=CW red=CW ← looks good here...
Step 5 (R): blue=CW red=CCW
Step 6 (B): blue=CCW red=CCW
→ Loop: both CCW ≠ start CW ✗

The Numbers

At every step count, exactly 25% of all possible patterns are LOOP-clean. Each hand independently has a 50% chance of even count (half of all subsets of N have even size). Two independent 50% events: 0.5 × 0.5 = 0.25.
