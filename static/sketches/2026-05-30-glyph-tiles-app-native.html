Why this unifies

The glyph uses the exact NavButton trick — a per-color gradient clipped to the icon text — so an action's color lives in the glyph, never as white-on-a-color-chip.

The tile chrome (12px radius, translucent resting bg, hover-lift, accent border) is the dock-btn language from the Mandala dock you liked.

Tint 0 = Mono (neutral tiles, color only in the glyph — calmest, most cohesive).
Tint ~50 = subtle Aurora (gentle per-action wash).
Emboss ON = the less-try-hard raised matte you leaned toward.

Same DNA can re-skin the viewer sidebars next, so the whole app reads as one mobile language.
