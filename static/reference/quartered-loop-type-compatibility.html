Which Types Qualify

A quartered seed must start at position P and end at the 90°-rotated counterpart of P (e.g. alpha1 → alpha3). That means the letter must travel within the same position family and reach a specific neighboring grid point. Only Dual-Shift does this.

TypeNameWhere It Goes90° Verdict
1 Dual-Shift alpha → alpha alpha ↔ beta beta → beta gamma → gamma ✓ can reach 90° neighbor
2 Shift alpha → gamma beta → gamma gamma → alpha gamma → beta ✗ leaves family
3 Cross-Shift alpha → gamma beta → gamma gamma → alpha gamma → beta ✗ leaves family
4 Dash alpha ↔ beta gamma → gamma ✗ wrong endpoint
5 Dual-Dash alpha → alpha beta → beta gamma → gamma ✗ stays at same point
6 Static alpha → alpha beta → beta gamma → gamma ✗ stays at same point

Types 2 & 3 leave the starting family entirely. Type 4 crosses alpha ↔ beta, but the 90° endpoint stays within the same family (alpha1 → alpha3). Types 5 & 6 never move at all — they land on the same point they started. Only Type 1 can move within alpha (or beta, or gamma) to reach the 90° neighbor.
