# Screenshots Archive

Historical screenshots of TKA's development over time. Kept for reference — fun to look back at how things evolved.

## Folders

- **app-development/** — App UI screenshots from various stages of development
- **guide-artboards/** — Full-page Illustrator artboard exports from the Level 1 guide design process
- **dev-snapshots/** — In-progress screenshots from debugging, feature work, and UI iteration
