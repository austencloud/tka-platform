Every possible sequence for this configuration. Not favorites. Not a curated best-of. The complete set, printed.

TKA was built on the foundation of Vulcan Tech Gospel (VTG), created by Noel Yee and spinners at the Vulcan Lofts in Oakland. VTG gave flow arts its first shared language for timing and direction. TKA takes that foundation and adds a combined notation: both hands described together in a single letter. The VTG categories are still here, built into every card as a classification layer.

The System

TKA is a notation system for flow arts. Every movement a staff, fan, or club can make has a letter. Letters combine into sequences. Sequences loop back on themselves through mathematical transformations. Each transformation type produces a complete, finite set of sequences.

That finite set is a deck.

These two decks are the beginning. The system produces new decks algorithmically. Different LOOP types, beat lengths, difficulty levels, transformation combinations. A new deck every week for the next ten years and you still wouldn't exhaust the space.
