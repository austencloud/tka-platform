# Ember midflank surface assets

`rock-ground-color.jpg` is the unmodified 1K diffuse map from Poly Haven's
[Rock Ground](https://polyhaven.com/a/rock_ground), by Rob Tuytel.
[CC0](https://polyhaven.com/license) permits commercial use, modification and
redistribution. No attribution requirement or share-alike obligation applies.

Provider file: `rock_ground_diff_1k.jpg`. Provider and downloaded MD5:
`5e897f7e2bcf857250bf74be878584b2`. Retrieved September 5, 2026, through the public
asset API and its download URL. The runtime darkens the scan through the shared
ground-detail material; the source image is unchanged.

`family-mask.png` is original procedural placement data generated by
`scripts/ember-midflank-production.py`. It places fractured basalt across the
mountain, with an ash contribution around the small cleared bench. It is not
a copy of the previous scene's flow mask. The existing R11 height scan and
original R9 young-lava, iron-contact and sheltered-ash maps remain shared assets.
