# Ember R11 ground micro-surface

The height map in this folder comes from Poly Haven's
[Rock Ground](https://polyhaven.com/a/rock_ground) material by Rob Tuytel.
Poly Haven publishes the asset under CC0.

| Local file               | Poly Haven source         | Provider MD5                       |
| ------------------------ | ------------------------- | ---------------------------------- |
| `rock-ground-height.jpg` | `rock_ground_disp_1k.jpg` | `f89ce9115ebd7d00070a42480e28295d` |

The file is retained at the provider's 1K resolution. Ember uses it as a
color-neutral micro-surface layer beneath its authored Fresh Rift families.
The scan supplies physical breakup without replacing the scene's lava,
iron-contact, fractured-basalt, or ash color, normal, and roughness maps.
