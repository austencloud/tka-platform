# Ember R11 ground micro-surface

The height and roughness maps in this folder come from Poly Haven's
[Rock Ground](https://polyhaven.com/a/rock_ground) material by Rob Tuytel.
Poly Haven publishes the asset under CC0.

| Local file                  | Poly Haven source          | Provider MD5                       |
| --------------------------- | -------------------------- | ---------------------------------- |
| `rock-ground-height.jpg`    | `rock_ground_disp_1k.jpg`  | `f89ce9115ebd7d00070a42480e28295d` |
| `rock-ground-roughness.jpg` | `rock_ground_rough_1k.jpg` | `67be099b9edb59d2fcb3377c5fccbf88` |

The files are retained at the provider's 1K resolution. Ember uses them as a
color-neutral micro-surface layer beneath its authored Fresh Rift families, so
the scanned rock supplies physical breakup without replacing the scene's lava,
iron-contact, fractured-basalt, or ash art direction.
